# Meine ersten Schritte mit Git

Dieses Repository habe ich im Rahmen meines Studiums angelegt.
Ich habe gelernt, wie man Dateien versioniert und Änderungen nachverfolgt.

## Wichtige Git-Begriffe
- Repository: Ordner, in dem Git alle Versionen eines Projekts speichert
- Commit: gespeicherter Stand der Änderungen mit einer Nachricht
- Branch: eigener Entwicklungszweig, um Änderungen getrennt zu testen
